# Solar Flow

让钱流向生活。Solar Flow 是一款离线优先、以人民币为默认单位的个人收支管理 PWA，支持手动记账、微信/支付宝等账单导入、独立账本、资金分配和可选的跨设备同步。

![Solar Flow](public/icon-192.png)

**在线体验：** <https://solar642.github.io/solar-flow/>  ·  **使用指南：** [docs/USER_GUIDE.md](docs/USER_GUIDE.md)  ·  **隐私说明：** [docs/PRIVACY.md](docs/PRIVACY.md)

> 涉及个人财务。建议先用空白或测试账本熟悉规则，再决定是否启用云同步。公开演示站的云数据由 Solar Flow 项目配置的 Firebase 服务承载；同步不是端到端加密，项目管理员在技术上可能访问云端记录。若不接受这一点，请保持本机使用，或部署到自己管理的 Firebase 项目。

## 功能

- **本机优先：** 无需登录即可记账；浏览器本机保存，首次加载后可离线使用。
- **账单导入：** 支持 XLSX、XLS、CSV、OFX；文件在浏览器内解析，先预览、分类和去重，再导入。原始文件不会上传，但解析出的交易及部分来源文件名/行号会随账本同步。
- **单一总资产口径：** 不把微信、支付宝或银行卡建成余额账户；账单来源标签仅用于识别重复流水。
- **独立账本：** 每个账本分别保存总资产基准、流水、资金分配、计划、借款清单和导入批次；新账本从 0 开始。
- **资金分配：** 消费依次从生活资金、未分配的其他资金、自由资金、计划资金、紧急资金扣除。紧急资金线是动态建议，不是硬性目标。
- **收支复盘：** 日历、趋势/柱状图、分类构成及月度/年度回顾；建议基于已记录数据，样本不足时会降低结论强度。
- **可选云同步：** 邮箱注册并验证后，可在同一账号下同步账本数据。计划封面图片保存在设备本机，不上传。
- **PWA：** 手机可以安装到主屏幕。Android 推荐 Chrome（Edge 也可尝试）；iPhone/iPad 使用 Safari。步骤见 [手机快捷方式指南](docs/USER_GUIDE.md#手机快捷方式)。

## 快速开始

需要 Node.js 22 或更高版本。

```sh
npm ci
npm run dev
```

浏览器打开 <http://127.0.0.1:5173/solar-flow/>。没有 Firebase 配置时，离线/本机记账仍可用，云登录与同步不会启用。

```sh
npm test       # 单元与同步逻辑测试
npm run build  # 生产构建
```

本地使用云端功能时，复制 `.env.example` 为 `.env.local`，填写你自己 Firebase Web app 的客户端配置。`.env.local` 已被 Git 忽略。Firebase Web 配置会出现在浏览器静态资源中，不能当作秘密；真正的访问控制必须由 Firestore Security Rules 实现。部署说明见 [开发与部署](docs/DEVELOPMENT.md)。

## 重要数据规则

| 场景 | Solar Flow 的处理方式 |
| --- | --- |
| 总资产基准 | 记录某一日期“已结清”的总资产；基准日前的历史流水只用于统计，之后的收入/支出调整当前资产。基准日当天按已结清处理，补算整天流水时应把基准日设为首笔流水前一天。 |
| 账单去重 | 优先使用同来源交易流水号；缺少流水号时使用来源、日期、方向、金额（分）和标准化商户组成的指纹。详细规则和跨来源限制见[数据与冲突规则](docs/DATA_AND_SYNC.md)。 |
| 内部转账 | 能从账单字段识别为转账/中性记录的行不进入收支和资产变化。应用不会跨来源自动配对所有转入/转出；导入预览仍需核对。 |
| 云端冲突 | 按单条记录的更新时间采用最后写入优先；同一条记录的并发编辑不会做字段级合并。不同 ID 的交易会保留，重复导入仍按去重规则收敛。 |
| 隐私 | 原始账单文件和计划封面不上传；云同步会上传解析后的账本记录。应用没有端到端加密。完整范围见[隐私说明](docs/PRIVACY.md)。 |

这些规则是数据正确性的关键，导入多年流水或更改资产基准前请先阅读[用户指南](docs/USER_GUIDE.md)和[数据与同步规则](docs/DATA_AND_SYNC.md)。

## 项目状态

Solar Flow 仍在持续迭代。导入识别和分类规则会尽量给出提示，但不是金融机构对账服务；请检查预览，不要把自动分类当作最终财务凭证。Firebase、浏览器存储和设备安装行为可能受服务配额、网络及浏览器版本影响。
