# 隐私与安全边界

Solar Flow 管理个人财务信息。公开仓库只包含应用源代码、合成测试数据和经过整理/脱敏的产品需求纪要；不应把真实账单、真实账号或个人截图提交到仓库。

## 数据在哪里

### 未登录 / 本机使用

- 账本状态保存在当前浏览器的本机存储中；计划封面图片存在本机 IndexedDB。
- 应用静态文件由 GitHub Pages 提供。没有配置 Firebase 或没有登录时，应用不连接账本云同步。
- 浏览器清除站点存储、卸载/重置浏览器或设备损坏可能造成仅存在本机的数据丢失；请定期使用“导出当前账本”保存备份。

### 用户主动登录并验证邮箱后

- Firebase Authentication 处理邮箱账号、密码验证与验证邮件。
- Cloud Firestore 接收同步所需的解析后账本对象，例如账本名称和基准、交易日期/方向/金额/商户/分类/备注/来源信息、计划数据、借款/信用条目、导入批次及用户分类规则。
- 导入文件的交易行在浏览器解析。原始 XLSX/CSV/OFX 文件本身不会上传，但交易记录中的来源文件名/行号等元数据可能同步。
- 计划封面图片文件只保存在设备 IndexedDB；计划对象中的封面 ID 等字段可能同步，图片本身不会上传。
- 当前公开部署将 Firestore 放在香港区域。自行部署者应检查自己 Firebase 项目的区域、服务条款、保留策略与适用法规。

## 谁能访问云数据

现有 Firestore Security Rules 要求用户邮箱已验证，并将读/建/改限制在登录用户自己的 `users/{uid}/records` 路径；规则禁止客户端物理删除文档。该规则用于隔离普通用户，**不等于端到端加密**：Firebase 项目管理员/具备相应管理权限的人员在技术上可以访问项目数据。公开演示站的同步数据由项目所有者控制的 Firebase 项目承载。

如果你不信任托管方或不希望云端保存金融记录，请不要登录启用同步；可以只用本机模式，或按[开发与部署说明](DEVELOPMENT.md)创建并管理自己的 Firebase 项目。

## 明确不承诺的事项

- 应用没有端到端加密，不能保证项目管理员无法读取同步内容。
- 应用不是银行、审计、税务、投资或信贷系统；自动分类和总资产计算需要用户核对。
- 当前没有专门的 Firebase Auth 账号删除/完整云数据清除流程。“清空当前账本”会同步账本记录的删除标记，但不是物理删除，也不会删除认证账号。需要删除云端账号/数据时，应先暂停使用并通过仓库维护渠道联系项目维护者；不要在公开 Issue 贴账单或账号信息。
- Firebase 使用配额、收费规则、浏览器存储策略和服务可用性可能变化；部署者应自行监控并告知用户。

## 公开仓库的安全注意事项

- `.env.local`、真实账单、导入预览、邮箱、认证链接、Firebase 服务账号 JSON、私钥和云端文档都不应提交。
- Firebase Web app 的客户端配置会出现在浏览器中，API key 是项目标识而非访问控制。绝不把服务账号密钥或管理员令牌放进 `VITE_*` 变量。
- 问题报告只提供可复现步骤和脱敏的虚构示例。发现安全漏洞时请遵循 [SECURITY.md](../SECURITY.md)，不要公开披露可利用细节。
